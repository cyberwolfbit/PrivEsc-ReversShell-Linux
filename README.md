# PrivEsc + ReversShell (Linux)

Este repositorio recoge recursos, notas y ejemplos relacionados con la escalada de privilegios en sistemas Linux y el uso de reverse shells en entornos controlados. Se centra en la comprensión de técnicas comunes de elevación de privilegios, ejecución de comandos con mayores permisos y establecimiento de conexiones remotas en escenarios de laboratorio.

Se abordan vectores típicos como configuraciones inseguras, permisos mal definidos y servicios mal configurados, junto con ejemplos prácticos de reverse shells para entender su funcionamiento a nivel de sistema y red.

El contenido está orientado a usuarios con conocimientos básicos de Linux y redes que busquen aprender de forma estructurada sobre seguridad ofensiva y análisis de vulnerabilidades en entornos educativos.
